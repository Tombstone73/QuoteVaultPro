# Lovable UI reference

This directory is a visual and interaction reference only. It is not the production V2 application and does not connect to V2 APIs, backend services, or database state.

## Product Builder reference

- Route: `/product-builder`
- Entry: `src/routes/_shell.product-builder.tsx`
- Components: `src/components/app/product-editor/`
- Mock product model and preview data: `src/lib/mock/product-editor.ts`

The Product Builder import is intentionally self-contained so it can be inspected, run locally, and used as a design reference without changing production behavior.
