# Assistant capabilities and confirmations

The assistant provides System Guide explanations, current-screen help, approved read-only record context, and only three existing confirmation-gated production commands. Free-text GO never executes a command. External research, MCP, SQL, invoice mutations, and fulfillment mutations are unavailable.
